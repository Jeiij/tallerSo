# Taller de Sistemas Operativos (tallerSo)

Repositorio de ejercicios propuestos para el Taller de Sistemas Operativos.

## Descripción

Este repositorio contiene los ejercicios prácticos desarrollados como parte del Taller de Sistemas Operativos. Aquí se trabajarán conceptos como:

- Gestión de procesos
- Gestión de memoria
- Sistemas de archivos
- Comunicación entre procesos (IPC)
- Sincronización y concurrencia

## Estructura del Proyecto

```
tallerSo/
├── README.md
└── ejercicios/   # Carpeta con los ejercicios propuestos
```

## Requisitos

- Sistema operativo Linux (recomendado)
- Compilador GCC
- Make

## Uso

Cada ejercicio se encuentra en su propia carpeta con instrucciones específicas para compilar y ejecutar.

## Estudiante

Este repositorio está desarrollado como parte de un curso académico con acceso a GitHub Copilot a través del programa **GitHub Education** para estudiantes verificados.
